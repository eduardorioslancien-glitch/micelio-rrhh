Probar que n8n llega a MICELIO

En n8n crea un nodo HTTP Request: método GET, URL https://micelio.digetelperu.com/api/ping, y un header X-API-Key con la clave del API (la misma LEADS_API_KEY). Si responde {"ok": true}, la conexión está bien y aparecerá abajo como llamada entrante. Respuesta 401 = clave distinta; 503 = el servidor no tiene la clave configurada.
